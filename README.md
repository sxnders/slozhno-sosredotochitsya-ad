# Сложно сосредоточиться

Адаптивный лендинг на тему концентрации внимания: тёмная и светлая темы, переключение темы кнопками и автоматически по системным настройкам (`prefers-color-scheme`).

## Что внутри

- семантическая вёрстка по методологии БЭМ;
- подход mobile first, брейкпоинты 768px и 1024px;
- CSS-переменные для цветов, шрифтов и отступов;
- сетка на CSS Grid, текст через `clamp()`;
- галерея с ленивой загрузкой изображений.

## Структура

- `index.html` — разметка страницы;
- `styles/` — стили: `variables.css`, `style.css`, `dark.css`, `light.css`;
- `fonts/`, `images/` — шрифты и изображения;
- `scripts/script.js` — переключение темы.
